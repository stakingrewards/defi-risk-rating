# DeFi Risk Rating – Rating Challenges

This repository is the public home for **rating challenges** to the Staking Rewards DeFi Risk Ratings.

If you believe a published rating is inaccurate, outdated, or missing important context, you can raise a **rating challenge** here so the Risk team can review, discuss, and, if warranted, update the rating.

---

## How to Challenge a Rating

To challenge a rating, please open a **GitHub Issue** in this repository and follow the process below.

### 1. Check existing issues

Before creating a new issue:

- Browse **Open issues** to see if someone has already challenged the same protocol.
- If a relevant issue exists, add your input as a comment instead of opening a duplicate.

### 2. Create a new issue

If no existing challenge fits your case:

1. Click **“New issue”**.
2. Use the **“Rating Challenge”** template from this README (see below).
3. Use a clear title, for example:

   - `Valantis - Staked HYPE`
   - `HyperLend - Hype Core Market on HyperEVM`

### 3. Provide the required information

Every rating challenge **must** include:

- **Protocol name**
- **Reason for the challenge**
- **New proposed rating**
- **Evidence of your reasoning**

The more specific and evidence-based your challenge is, the easier it is to review.

### 4. Follow the discussion

- The Risk team may ask follow-up questions in the issue.
- If the challenge is accepted, the rating and/or accompanying report will be updated and the outcome will be documented in the issue.

---

## What Makes a Good Rating Challenge?

Strong challenges typically:

- Point to **concrete changes** or data (e.g., new audits, major incidents, governance changes, tokenomics updates, TVL / liquidity shifts).
- Reference **verifiable sources**:
  - Audit reports
  - Governance proposals
  - On-chain transactions
  - Incident post-mortems
  - Official documentation, dashboards, or oracles
- Explain **why** the change materially affects the **risk of permanent capital loss**.
